# Rydzo 🚗

Backend services for **Rydzo**, a smart carpool platform focused on daily or outstation commute.

## Tech Stack
- Java 21
- Spring Boot 3
- Spring Cloud Gateway
- PostgreSQL
- Kafka (planned)
- Docker & Kubernetes (planned)

## Repository Structure
rydzo-backend
├── api-gateway
├── auth-service
├── user-service
├── ride-service
├── common


## Services
- **API Gateway** – Entry point for all client requests
- **Auth Service** – Authentication & authorization
- **User Service** – Rider and driver profiles
- **Ride Service** – Carpool, matching, rides
